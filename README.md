## O que eu construo

- **Pipelines ETL/ELT multi-tenant**: extratores em Python para APIs de ERPs (Omie, Conta Azul, Tiny e Bling) rodando como Cloud Run Jobs agendados no GCP, com credenciais no Secret Manager e CI/CD via Cloud Build
- **Arquitetura Medallion no BigQuery**: dados brutos na camada bronze, modelados em SQL na camada silver como tabelas dimensão e fato prontas para consumo analítico
- **IA aplicada a dados**: aplicações com LLMs para consulta de dados em linguagem natural, combinando text-to-SQL e RAG, e modelos preditivos com BigQuery ML
- **Análise de Dados e BI**: dashboards em Power BI e Microsoft Fabric que orientam a gestão de receita e novas oportunidades de negócio

## Resultados

- Mais de **100 clientes** atendidos
- Integração e dashboards para **38 empresas** de uma mesma carteira
- Monitoramento de mais de **R$ 6,8 milhões em fretes** de uma agroindústria com operação em 4 estados, substituindo processos manuais em Excel por análises automatizadas via API
